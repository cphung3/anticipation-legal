# ANTicipation — legal pages

Static hosting for the **ANTicipation** app's public legal pages, served via GitHub Pages.

- `/privacy/` — privacy policy
- `/delete-account/` — account-deletion instructions

Source of truth for the copy lives in the (private) app repo under `docs/privacy_policy.md`
and `docs/delete_account.md`. Update both together so they do not drift.
